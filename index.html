Network and Communications Assignment

About:

This assignment details the design and implementation of a network topology for a global e-commerce company's HQ at Loyang Crescent and a new warehouse at Tuas Crescent. The design adheres to the specified requirements and includes various networking features.

Routing:

Dynamic routing is used, offering significant advantages over static routing, including automatic updates, resilience, redundancy, efficient network utilization, and scalability. Multi-area OSPF (Open Shortest Path First) is deployed, benefiting the network with scalability, fast convergence, VLSM support, and load balancing across multiple paths.

Design:

The topology assigns each VLAN a dedicated switch, with wireless routers included for VLANs with fewer clients, enhancing connectivity and flexibility. This design ensures segmentation for security, scalability for future expansions, and improved network performance by minimizing broadcast domains.

Features:

  • DNS & Web Server: Added to handle domain name resolutions and host internal web services, enhancing communication and availability.
  • SYSLOG Server: Centralizes logging of network events, improving monitoring, troubleshooting, and security.
  • NTP Server: Synchronizes time across all routers, ensuring consistent timekeeping and accurate time-stamping for network events.
  • PPP with PAP Authentication: Used for WAN links between HQ and the warehouse, providing secure connections, error detection, and bandwidth optimization.
  • Router-on-a-Stick: Enables inter-VLAN routing, utilizing a single physical router interface for multiple VLANs, improving cost efficiency and management flexibility.
  • Dynamic NAT: Allows internal networks to access the internet through a pool of public IP addresses, providing security by hiding internal IPs and conserving public IP resources.
  • Access Control Lists (ACLs): Implemented on the HQ router to control internet access, enhancing security by allowing only authorized internal networks and blocking specific traffic such as the cafe network from accessing internal web servers.

Systems and Network Security Assignment

About:

This project involved designing and implementing a secure and scalable enterprise network for SAFENET.com, connecting its headquarters and branch offices through simulated ISP routers. Built in Cisco Packet Tracer, the network mirrored real-world corporate infrastructure while ensuring reliable connectivity and strong security.

Routing:

Static routing was configured between HQ, Branch, and the ISP. This provided predictable paths, tighter control, and simpler management compared to dynamic protocols, ensuring stable communication across all networks.

Design:

The network was segmented into VLANs for servers, users, and management, with VTP propagation across HQ switches. Inter-VLAN routing enabled communication between departments, while DHCP automated IP assignment. A web server was hosted internally and published online through DNAT. NAT and PAT conserved public IPs for outbound traffic, while subnetting supported scalability across HQ and Branch.

Features:

  • DHCP & DNS: Dynamic IP assignment and name resolution across HQ and Branch.
  • NTP & Syslog: Synchronized clocks and centralized logs for monitoring.
  • NAT, PAT & DNAT: Secure internet access and internal web server publishing.
  • VPN (IPsec with ISAKMP): Encrypted site-to-site tunnel between HQ and Branch.
  • AAA & SSH: Centralized authentication via RADIUS and encrypted device management.
  • Firewall & ACLs: Traffic filtering to block unauthorized connections.
  • Intrusion Prevention System (IPS): Real-time threat detection and blocking.
  • Layer 2 Security: Port security, BPDU Guard, and rogue device prevention.
  • Wireless Security: WPA2-PSK with AES for secure wireless access.
  • Additional Hardening: Login banners, honeypot, SSH protections, and timeouts.

Systems and Network Security Project

About:

This project focused on designing and implementing a secure, scalable, and sustainable enterprise-grade campus network for Nanyang Polytechnic using Cisco Modeling Labs (CML) integrated with VMware virtual machines. The Proof of Concept (POC) supported online learning and research while ensuring reliable access for students, lecturers, and administrators on-campus and remotely.

Routing:

Dynamic routing was implemented using OSPF with selective static routes. This ensured fast convergence, scalability, and security while keeping sensitive LANs hidden from unnecessary advertisements.

Design:

The network was segmented into domains for NYP Core, School of IT, and School of Business Management, each with VLANs and subnets. A DMZ securely hosted public services (web, mail), exposed through static NAT to a simulated internet. Efficient subnetting and virtualization reduced IP wastage and supported scalability.

Features:

  • EtherChannels: Increased bandwidth and redundancy
  • DNS & ADDS: Domain resolution, user management, roaming profiles, GPOs (mapped drives, login banners)
  • HTTP, Mail, HTTPS/TLS & Certificate Authority: Web/email services with certificates and encrypted access
  • VPN & RADIUS: Encrypted remote access with centralized AAA
  • Firewalls & ACLs: Perimeter filtering plus host-based protection
  • IP Config, Routing, NTP & Syslog: Connectivity, synchronized clocks, and logs
  • Routing Protocol Authentication: Secured OSPF updates
  • DHCP: Automated IP assignment
  • VLANs, VTP, STP, Trunks & Inter-VLAN Routing: Segmentation, loop prevention, VLAN communication
  • Port Security, BPDU Guard, Root Guard & DTP Disabled: Blocked spoofing, STP attacks, unauthorized trunks
  • SSH & SSH Security: Encrypted device management with login controls
  • SFTP & FTPS: Secure file transfers
  • NAT & PAT: Conserved public IPs and enabled external access
  • Penetration Testing & Banner Hardening: Verified DMZ exposure, ACLs, minimized info leaks
